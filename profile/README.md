## 🌿 About

> **T4F** = Tech 4 Fertility · **MCA** = moncycle.app

Tech 4 Fertility (T4F) builds free and open-source software for people who use natural family planning and fertility awareness methods. Our tools are **self-hostable**, **privacy-by-design**, and **local-first**: your health data belongs to you.

## 📱 Moncycle.app

Our flagship project is [Moncycle.app](https://moncycle.app) (MCA), a menstrual cycle tracking app designed for natural birth control methods (aka natural family planning).

| Project | Description |
| --- | --- |
| [**MCA-web-app**](https://github.com/Tech4Fertility/MCA-web-app) | Web application (JavaScript) |
| [**MCA-backend-and-API**](https://github.com/Tech4Fertility/MCA-backend-and-API) | Backend and API (PHP) |
| [**MCA-Docker-image**](https://github.com/Tech4Fertility/MCA-Docker-image) | Docker image to self-host Moncycle.app |
| [**yunohost-package**](https://github.com/Tech4Fertility/yunohost-package) | YunoHost package for easy self-hosting |
| [**MCA-terminal-cli**](https://github.com/Tech4Fertility/MCA-terminal-cli) | Local-first command line client (Python) |
| [**MCA-landing-page**](https://github.com/Tech4Fertility/MCA-landing-page) | Presentation website for Moncycle.app |

Native Android and iOS apps are in development.
